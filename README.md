# Ink and Ember Forge website

This website acts as a personal portfolio and a project directory for the work I have published through Github.

## Description

This website is an introduction to me, InkAndEmberForge, as a website and software developer-in-training. It serves to showcase the work I have completed, the skills I have developed, and the journey I have taken to get to where I am.

It also houses a project directory covering the different projects I have developed to provide easy access to the different projects I have created.
